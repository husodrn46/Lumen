# Güvenlik politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri en güncel kararlı Lumen sürümü için hazırlanır. Eski
sürümler için düzeltme garantisi verilmez. Bildirim yapmadan önce sorunun en
güncel kararlı sürümde devam ettiğini kontrol edin.

| Sürüm | Güvenlik desteği |
|---|---|
| En güncel kararlı sürüm | Destekleniyor |
| Daha eski sürümler | Desteklenmiyor |

## Güvenlik açığı bildirme

Güvenlik açığını herkese açık issue, pull request veya tartışma olarak
paylaşmayın. GitHub üzerindeki
[özel güvenlik bildirimi](https://github.com/husodrn46/Lumen/security/advisories/new)
sayfasını kullanın.

Bildirimde mümkünse şunları ekleyin:

- Etkilenen Lumen sürümü veya commit kimliği
- Açığın etkisi ve gerekli ön koşullar
- Tekrarlama adımları veya küçük bir kanıt
- Varsa önerilen çözüm

Gerçek müşteri verisi, veritabanı parolası, erişim anahtarı veya canlı sisteme
ait kişisel bilgi paylaşmayın. Örnekleri sentetik verilerle hazırlayın.

Bildirim incelenmeden ve düzeltme yayımlanmadan ayrıntıları herkese açık hale
getirmeyin. Üçüncü taraf bir bağımlılığı etkileyen açıklar için ilgili projenin
güvenlik bildirim kanalını da kullanın.

## Kapsam

Bu politika Lumen kaynak kodu ve Lumen tarafından sağlanan yapılandırmalar için
geçerlidir. LOGO Tiger, Microsoft SQL Server, PHP ve diğer üçüncü taraf
bağımlılıkların kendi güvenlik politikaları vardır.
